# Limitations

- The prototype evaluates declared JSON snapshots. It does not inspect or
  mutate a live Git index, filesystem, branch, commit, pull request, or remote.
- CAP is a mechanical admissibility precheck. It does not issue authority,
  execute work, assess wisdom or commercial value, perform open-ended semantic
  judgment, or certify security or compliance.
- Presented authority is not proof that the issuer has real-world legal or
  organizational standing.
- CAP depends on declared source basis, authority, evidence, policies, and
  `evaluation_as_of`; it cannot independently prove those inputs describe the
  outside world.
- Path Gate is deterministic matching, not filesystem protection, hook
  enforcement, branch protection, tamper resistance, or a security boundary.
- Claims Gate checks an explicit structured inventory under closed rules. It
  is not a general truth detector and cannot discover every omitted, implied,
  or misleading claim.
- Evidence references are declared inputs. The prototype checks structure and
  linkage but does not independently verify external evidence.
- SHA-256 binds canonical bytes. It does not establish signer identity,
  non-repudiation, confidentiality, external timestamping, or authorization.
- Policy hashes prove which bytes were evaluated, not that a policy is
  correct, secure, lawful, complete, or suitable for a real organization.
- Bundled policies and fixtures are illustrative, not production policy sets.
- `HOLD` is not permission, partial acceptance, or an eventual `PASS`.
- Gate-order invariance applies only after CAP passes and among applicable
  domain gates that execute.
- Standalone reproduction establishes only the tested local dependency
  boundary. It is not broad platform or external validation.
- The included GitHub Actions workflow has been parsed and tested as source,
  but this candidate has not been published or run on GitHub.
- No deployment, support, service-level, or compatibility commitment is made.

## Plain-English glossary for preserved identifiers

**P11 and GASS are internal source-project identifiers referenced only in
preserved claim-boundary text. They identify systems and program stages that
this standalone prototype explicitly does not implement, qualify, or claim.**

- **GASS** names a broader private operating architecture. It is not included
  in this repository, and this demo does not claim qualification for it.
- **P11** names an internal program stage used to test governed operations.
  This repository is not a P11 run, completion record, or admission decision.

These strings remain in deterministic generated limitation text because
changing them would alter previously verified receipt hashes and replay
identity. They expose no internal code, configuration, history, or runtime
dependency.
